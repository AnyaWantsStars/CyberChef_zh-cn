# CyberChef_zh-cn

## Chinese

[English](#english) | [中文](#chinese)

**CyberChef 中文汉化版**

**非官方社区汉化，基于 CyberChef 发行版。**

覆盖界面文本、操作名称、操作说明、操作参数及提示和报错信息，已完成超过 90% 可见文本的汉化。

### 🚀 快速开始

前往 [Releases](https://github.com/GUETCA/CyberChef_zh-cn/releases) 下载最新版本，解压后直接运行。

### 📦 包含内容

- 完整的简体中文界面翻译
- 汉化的操作名称与说明
- 汉化的操作参数与输出
- 针对中文字符优化的样式调整
- 所有修改均为非功能性改动，核心逻辑保持不变

### 🛠 技术说明

本项目完全通过 AI 辅助开发，历经上百轮对话反复修改完善。基于官方发行版，采用规则驱动的自动化查找替换方式进行汉化。

**当前状态（v0.9.9）：**
- 约 90% 可见文本已完成汉化
- 由于时间和精力有限，尚未对全部 500 多个操作进行全面测试
- 部分操作可能存在功能问题——请注意，某些问题可能在原版中即已存在，并非均由汉化引入

### ⚠️ 已知限制

目前代码较为杂乱且不够完善，因此**暂不公开源码**。我们计划在 v1.0.0 版本发布前后整理代码并考虑开源。

如有兴趣参与贡献或协助增加更多语言版本，欢迎与我们联系！

### 🐛 问题反馈

欢迎提交 Issue 反馈以下问题：

| 问题类型 | 说明 |
|:---:|---|
| 汉化遗漏 | 仍有英文未翻译的可见文本 |
| 汉化不当 | 翻译不准确，或某些专业术语不应汉化 |
| 功能异常 | 原版正常但因汉化引入的功能问题 |

提交 Issue 时请尽量详细描述并提供必要的复现信息（如截图、流程、输入或错误信息等）。

## English

[English](#english) | [中文](#chinese)

**CyberChef Simplified Chinese Localization Pack**

**Non-official, community-driven Chinese localization for CyberChef.**

A comprehensive Chinese (Simplified) localization pack for [CyberChef](https://github.com/gchq/CyberChef), covering interface text, operation names, operation descriptions, operation parameters, prompts, and error messages. Over 90% of visible text has been localized.

### 🚀 Quick Start

Download the latest release from the [Releases](https://github.com/GUETCA/CyberChef_zh-cn/releases), extract, and run.

### 📦 What's Included

- Full Chinese (Simplified) translation for UI elements
- Localized operation names and descriptions
- Localized operation parameters and outputs
- Adjusted styles for better readability with CJK characters
- All modifications are non-functional — core logic remains untouched

### 🛠 Technical Notes

This project is built entirely through AI-assisted development (hundreds of iterative refinement rounds). Based on the official release version, it uses rule-based automated search-and-replace to localize content.

**Current Status (v0.9.9):**
- ~90% visible text localized
- Not all 500+ operations have been fully tested due to limited time and resources
- Some operations may exhibit functional issues. Note that certain problems might exist in the original release as well and are not necessarily introduced by localization

### ⚠️ Known Limitations

The source code is currently messy and incomplete, so it will **not be open-sourced at this stage**. We plan to clean up and publish the codebase around the v1.0.0 release.

**If you'd like to contribute or help add more language versions, feel free to reach out!**

### 🐛 Reporting Issues

We welcome issue reports for the following types of problems:

| Issue Type | Description |
|:---:|---|
| Missing Translations | Visible text still showing English |
| Inaccurate Translations | Wrong wording or terms that shouldn't be translated |
| Functional Regressions | Features broken specifically due to localization changes (not pre-existing bugs) |

When submitting an issue, please include detailed reproduction steps and necessary information such as screenshots, workflow, input data, or error messages.
