# CyberChef v11.6.0 zh-cn v1.1.1

本次版本跟随上游 CyberChef 11.6.0，本地化功能与 v1.1.0 保持一致。

## 下载

- `CyberChef_v11.6.0_zh-cn_v1.1.1.zip`
- `sha256digest.txt`

解压后打开 `CyberChef_v11.6.0_zh-cn_v1.1.1.html`，也可以部署整个目录离线使用。

## 主要内容

- 同步上游 11.6.0 的依赖与安全更新
- 同步上游的 CI、工作流与 Docker 相关调整
- 保留中英文流程（recipe）双向转换
- Node.js API 继续兼容官方英文参数和返回结构

## 已知限制

- 少量可见文本可能仍为英文。
- 浏览器差异和部分大型文件场景仍需要实际使用验证。
- 官方 CyberChef 的核心功能问题应提交到官方项目。

This release follows upstream CyberChef 11.6.0 with dependency, security and CI updates; localization behaviour is unchanged.
