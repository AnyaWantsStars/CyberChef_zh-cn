# CyberChef v11.5.5 zh-cn v1.0.0-rc.1

这是 CyberChef 中文版的第一个公开预发布版本，基于官方 CyberChef 11.5.0 及后续提交。

## 下载

- `CyberChef_v11.5.5_zh-cn_v1.0.0-rc.1.zip`
- `sha256digest.txt`

解压后直接打开 `CyberChef_v11.5.5_zh-cn_v1.0.0-rc.1.html`，也可以部署整个目录离线使用。

## 主要内容

- 汉化主要界面、操作名称、说明、参数提示和错误信息
- 保留 CyberChef 的 500 多个操作和标准执行流程
- 提供 GitHub Pages 在线版本
- 不包含运行时 i18n 框架

## 已知限制

- 分享链接使用中文操作名，官方英文流程（recipe）链接无法直接解析。
- 源码级汉化会改变 Node.js API 的参数名称和部分返回文本，依赖官方英文接口的脚本需要先做兼容性验证。
- 尚未对全部操作逐一测试，部分问题可能来自官方版本。

This is the first public preview release of the Simplified Chinese build, based on official CyberChef 11.5.0 and later upstream commits. It is marked as a pre-release while Node.js API compatibility and broader operation testing continue.
