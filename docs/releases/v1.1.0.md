# CyberChef v11.5.5 zh-cn v1.1.0

这是 CyberChef 中文版在 v1.0.0 之后的第一个功能更新版本，基于官方 CyberChef 11.5.0 及后续提交。

## 下载

- `CyberChef_v11.5.5_zh-cn_v1.1.0.zip`
- `sha256digest.txt`

解压后打开 `CyberChef_v11.5.5_zh-cn_v1.1.0.html`，也可以部署整个目录离线使用。

## 相比 v1.0.0 新增

- 内置 122 条流程模板，分为编码与格式化、哈希与加解密、CTF 解题、安全取证 4 类
- 模板支持中文关键词 tags 搜索、星标与收藏夹管理、点击模板即加入流程
- 内置 9 套汉化版配色方案：蔷薇粉、薄荷青、雾灰蓝、鎏金黄、青柠绿、晴空蓝、海洋蓝、紫罗兰、阳光橙
- 增加 Catppuccin、Nord、Dracula、Tokyo Night 四套开源配色方案
- 新增界面设置窗口，支持跟随系统、固定浅色、固定深色和自定义主题
- 操作列表支持单击操作即加入流程，操作搜索升级为五级中英双语匹配
- 中文操作别名扩充到 655 个，覆盖 311 个操作
- 默认隐藏不常用操作，设置中可搜索并自定义隐藏项，也可一键显示全部操作
- 页眉构建日期改为可点击的更新日志入口，分别指向官方更新日志和汉化版更新日志
- 下载窗口中的官方提交编号改为构建时注入

## 兼容性

- 保留中英文流程（recipe）双向转换
- Node.js API 继续兼容官方英文参数和返回结构

This update adds the built-in recipe template library, an interface settings window with localized and open-source colour schemes, five-level bilingual operation search, and single-click operation loading on top of v1.0.0. Core CyberChef issues should be reported upstream; localization and fork-specific compatibility issues belong in this repository.
