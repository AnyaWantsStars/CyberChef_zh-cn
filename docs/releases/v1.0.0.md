# CyberChef v11.5.5 zh-cn v1.0.0

这是 CyberChef 中文版的第一个稳定版本，基于官方 CyberChef 11.5.0 及后续提交。

## 下载

- `CyberChef_v11.5.5_zh-cn_v1.0.0.zip`
- `sha256digest.txt`

解压后打开 `CyberChef_v11.5.5_zh-cn_v1.0.0.html`，也可以部署整个目录离线使用。

## 主要内容

- 汉化主要界面、操作名称、说明、参数提示和错误信息
- 提供中英文流程（recipe）双向兼容
- 恢复 Node.js API 的英文参数和官方调用兼容
- 保留 CyberChef 的 500 多个操作和标准执行流程
- 提供 GitHub Pages 在线版本

## 已知限制

- 少数可见文本可能仍为英文。
- 浏览器差异和部分大型文件场景仍需要实际使用验证。
- 官方 CyberChef 的核心功能问题应提交到官方项目。

This is the first stable release of the Simplified Chinese build, based on official CyberChef 11.5.0 and later upstream commits. Core CyberChef issues should be reported upstream; localization and fork-specific compatibility issues belong in this repository.
