        X 功能是如何工作的？

        CyberChef 具有上下文帮助功能。只需将光标悬停在你想要了解的功能上，然后在键盘上按 F1 即可获得相关信息。立即试试：把光标悬停在这段文字上并按 F1！


        我能用 CyberChef 做哪些事情？

        CyberChef 中有 数百个操作，使你能够轻松完成简单和复杂的任务。以下是一些示例：

        • 解码 Base64 编码字符串
        • 将日期和时间转换为不同时区
        • 解析 Teredo IPv6 地址
        • 将十六进制转储数据转换后再解压缩
        • 解密并反汇编 shellcode
        • 将多个时间戳显示为完整日期
        • 对不同类型的数据执行不同的操作
        • 将输入的部分内容用作操作的参数

        可以直接从文件加载输入吗？

        可以！只需将文件拖到输入框上并放下即可。

        CyberChef 可以处理最大约 2GB 的文件（取决于你的浏览器），但某些操作在如此大的数据上可能需要运行很长时间。

        如果输出超过某个阈值（默认 1 MiB），它将以可下载文件的形式提供。如需检查，可以查看文件的片段。


        如何一次对多个输入运行同一操作？

        也许你有 10 个时间戳要解析，或者 16 个使用相同密钥的编码字符串。

        “分支”操作（位于“流程控制”类别）会逐行拆分输入，并分别对每一行运行后续所有操作。每个输出会显示在独立的一行上。分隔符可以更改，因此如果输入以逗号分隔，可以将分隔符改为逗号。

        点击此处查看示例。


        “魔术”操作是如何工作的？

        “魔术”操作使用多种方法来检测编码数据以及可用来解读数据的操作。这些方法的技术描述可在此处找到。

        是什么
        
                                
        一个简单直观的 Web 应用，用于分析和解码数据，无需处理复杂的工具或编程语言。CyberChef 鼓励技术或非技术背景的人员去探索数据格式、加密和压缩。

        

                                
        为什么
        
                                
        在现代世界中，数字数据有各种形式、大小和格式——CyberChef 致力于在一个易用的平台上帮助你理解这些数据。

        


                                
        怎么做
        
                                
        界面以简洁为核心进行设计。复杂的技术现在如同拖放般简单。可以组合简单功能以构建“流程”，从而可能实现复杂的分析，并可与其他用户共享，使用他们的输入。
        
                                
        对于熟悉编写代码的人来说，CyberChef 是一种快速高效的原型问题解决方案的方式，验证可行后可再编写脚本实现。

        


                                
        面向谁
        
                                
        预计 CyberChef 将对网络安全和杀毒公司很有用。它也会吸引学术界以及任何参与数字数据分析的个人或公司，无论是软件开发人员、分析师、数学家，还是业余的解谜爱好者。

        


                                
        目标
        
                                
        希望通过 GitHub 发布 CyberChef，让更多人参与贡献，并将其整合到未来版本中。

        


                                
        
                                
        对于任何从事互联网相关工作的人来说，CyberChef 中有 数百个有用的操作，无论你是想将时间戳转换为不同格式、解压 gzip 数据、生成 SHA3 哈希，还是解析 X.509 证书以查看其颁发者。
        
                                
        它就是网络瑞士军刀。

            下载 CyberChef
            
                    
            
                    
            
                        
            CyberChef 完全在浏览器内运行，没有服务端组件，因此无论你使用 CyberChef 官方在线版还是下载的独立版本（假设未被修改），你的输入数据和流程配置都不会被发送到任何地方。
            
                        
            有三个操作会调用外部服务：“Show on map”操作会从 wikimedia.org 下载地图瓦片，“DNS over HTTPS”操作会使用 Google 或 Cloudflare 服务解析 DNS 请求，“HTTP request”操作则会调用你输入的已配置 URL。你可以通过浏览器的开发者控制台（F12）并查看 Network 标签来确认发出了哪些网络请求。
            
                        
            如果你希望下载自己的独立版 CyberChef 以在隔离网络或互联网受限/无网络的环境下运行，可从下方获取包含整个 Web 应用的 ZIP 文件。无需任何配置即可在本地运行或部署到 Web 服务器上。
            
                        
            请注意，独立版本永远不会自动更新，这意味着在手动重新下载新版本之前，它将不会收到错误修复或新功能。
